# 既存Sheetsの読み取り調査と移行対応

2026-10-12（JST）に、共有された正本のメタデータ・全管理タブのヘッダーと式を読み取り確認した。原本への書き込みは行っていない。ブックID・実データ・Notion URLは公開リポジトリへ保存しない。取得した式付きスナップショットは作業環境のリポジトリ外に保管した。元の旧17テーブルは存在せず、9管理タブと一時取得タブがある。

| 既存タブ                 | 読み取り時の記録行 | 対応候補                                | 保留する意味                                                                                                                      |
| ------------------------ | -----------------: | --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Race                     |                 19 | races / course_layouts / race_snapshots | race_keyは旧外部キーとして保持。track名だけでコースを同定しない。取得・利用可能時刻やコース形状が欠測                             |
| Prediction               |                137 | predictions / horse_evaluations         | phaseとrace_keyで版を分離。スコアは確率ではない。horse_name/jockey_nameだけで統合しない。全出走馬・snapshot・取得時刻の確認が必要 |
| Bet                      |                  8 | recommendations または virtual_bets     | 複数券が一つの文字列。本人購入か推奨の仮定収支か未確認。adoptedだけで購入と解釈しない。券単位への分割は人が確認                   |
| Results                  |                  8 | race_results / payouts                  | 上位3頭だけでは全着順・取消・同着を復元できない。券種別払戻の追加確認が必要                                                       |
| DailySummary             |         1 + 集計式 | APIで別集計                             | 過去の参考収支を本人購入の回収率へ混ぜない                                                                                        |
| HorseStats / JockeyStats |             集計式 | entity_features                         | 現在の集計は当時の特徴量へ遡及使用できない                                                                                        |
| ModelStats               |         6 + 集計式 | 比較用参考表示                          | 印・集計を確率校正済み指標と解釈しない                                                                                            |
| Meta                     |                 71 | 接続・運用の参考                        | 旧schema_version v2.0と新規契約0.2は別体系。元タブは上書きしない                                                                  |
| 一時取得タブ             |       IMPORTHTML式 | 対象外                                  | 検証済みの取り込み・出典とは扱わない                                                                                              |

行数は先頭のキーがある記録行。数式行・ヘッダー・空行は除外。数式の全列参照があるため、固定行数の設計へ勝手に書き換えない。

新規APIは `TL_<table>` の26専用タブを使う。既存9タブは `/api/legacy` から最大500行ずつ読み取り表示する。新規専用タブを作成する管理操作は `/api/sheets/provision`。この操作は今回実行していない。

安定IDはsource + external_idを確認してから発行する。名前一致で馬・騎手をマージしない。日時はUTC、開催日と予算はJST。距離m・時間秒・重量kg・円整数。未知値はnull、0は観測値。旧日時の+09:00は明示的にUTC変換してから取り込む。取得時刻を現在で補い、過去の予想入力として扱うことは禁止。

データ取得元は旧記録にJRA/NARの公式URLがある。新規の自動スクレイピングは実装せず、既存ChatGPTタスクが確認した出典付き入力を使用する。利用条件・取得制限は外部取得機能を追加するときに別途確認する。
