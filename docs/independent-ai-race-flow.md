# 独立評価＋AI展開判断 v2（段階導入）

## 目的
馬の能力・騎手技術・人馬の適合性を混同せず評価し、過去の数値統計を根拠に使いながらも、最終印・展開・購入候補は説明可能なAI判断にする。予想の根拠にオッズ・人気を使わない。予想固定後の市場価格チェックは別段階。

## 収集→独立評価→統合
1. 出走表・全頭の近走3走・同場騎手統計・馬場・当日傾向を出典と時刻つきで保存。欠測は null。
2. 馬の印（騎手評価を除外）と騎手の印（馬の強さを除外）を独立に出す。
3. 人馬コンビの過去の実績と脚質・乗り方の適合性を別に評価する。未騎乗は「不明」。
4. スロー・ミドル・ハイの隊列、主展開、逆転条件を比較して最終印を決定する。旧6項目の0〜100点とPython集計は保持するが、機械的な総合点順にしない。
5. AIは bet/skip を明示。買うなら根拠ある必要最小限の券種・点数と重複リスクを説明。見送りのとき数値モデルから6点補充しない。
6. 発走前の価格確認・期待値検証は別レーンに維持し、結果後に馬印・騎手印・相性・展開・買い方を個別検証する。

## 実装範囲
- `scripts/independent-ai-assessment.ts`: AIへの出力仕様と全出走馬の完全性検証。重複馬番・欠測馬番・無効な展開を拒否。
- `scripts/local-prediction-worker.ts`: AI自由予想モードに新プロンプトを接続。独立印と理由を既存Lab JSONの `independent_assessment` に保存（保存前に検証）。
- `scripts/bet-plans.ts`: 新しい独立評価が成立した場合に、AIの明示的な `skip` や無効な買い目を固定6点に置き換えない。旧レコードは従来動作のまま。
- `tests/independent-ai-assessment.test.ts`: 印の完全性・重複拒否・AI見送り時の無投票をテスト。
- `apps/web/src/main.tsx`: レース詳細で独立印・判断理由・主展開を表示。買い目の選定元（AI独立評価／AI／数値モデル）を明示。

## 現時点の限界・次の段階
- このPRは**AI自由予想と的中狙い600円レーンに限定した互換導入**。期待値400円レーンや従来数値選択レーンは比較用として残る。画面の主力表示は別途切り替えが必要。
- 騎手の詳細統計は既存CSV・公式資料で得られる範囲のみ。騎手技術に関する新しいDBテーブル、統計収集の拡張、過去コンビ・乗り替わり集計、騎手の技術統計を独立して蓄積するDBや専用ダッシュボードは次フェーズ。
- `hit_picks` は既存スキーマにより券種5種・600円以下。全面的なAI自由予算への移行には保存契約・UI・学習台帳・精算の同時改修が必要。
- 計画上の的中/回収率向上は未検証。発走前に凍結した予測だけを、時系列分割で旧方式とペア比較する。実馬券の自動購入は行わない。
