# UI/UX 再設計計画（2026-11-13）

本人の声：「分かりづらい・重要な情報が埋まっている・戻れない・再予想しづらい・結果が見づらい」。
画面ごとに「その時ユーザーが何をしたいか」を先に決め、それに合わせて配置と導線を作り直す。

## 1. 共通の導線

| 課題 | 原因 | 対応 |
| --- | --- | --- |
| 戻れない | 画面切替がReactの内部状態だけで、ブラウザの「戻る」やスワイプバックが効かない | URLハッシュで画面を表す（`#/today/2026-11-13`、`#/race/<id>/result` など）。戻る・再読込・ブックマーク・共有が効く |
| 迷う | スマホの上部ナビが横スクロールで、一部が隠れる | スマホは画面下の固定タブバー（今日／取込／成績／DB／設定） |
| レース間の移動が面倒 | 詳細から一覧に戻ってから別レースを開く必要がある | レース画面の上部に「‹ 前のR ／ 次のR ›」（同じ競馬場）と「一覧へ」を常に表示（固定ヘッダー） |
| 埋まっている | 1ページに全項目を縦に並べ、重要情報が下の方や折りたたみの中 | レース画面を目的別のタブに分ける。開いた時は「今の局面で一番見たいタブ」を自動で選ぶ |

## 2. 画面ごとの目的と配置

### 今日のレース（ホーム）
ユーザーの目的：今日どのレースがあるか／次はどれか／自分の印は何か／買ったか／結果はどうだったか。

- 上部：日付切替、予算・購入・損益サマリー、**次のレース**の帯
- 競馬場ごとのレース一覧。各レースに印（◎○▲）、購入状況
- **結果が出たレース**：着順に加えて「◎は何着」「的中／不的中」「損益」を一目で
- 自動処理・同期・履歴はページ下部にまとめる（運用確認用）

### レース画面
上部固定：競馬場・R・発走時刻・残り時間・状態、前後のRへの移動、一覧へ戻る。

| タブ | ユーザーの目的 | 内容 |
| --- | --- | --- |
| 予想 | 何を買うべきか判断したい | 印と勝率・複勝率バー、展開3シナリオ、参考買い目、予想版の切替。**再予想** への入口 |
| 出走馬 | 各馬・騎手の特徴を知りたい | 枠色の馬番・騎手・斤量、**傾向タグ**（馬・騎手）、近走3走 |
| 購入 | 仮想馬券を買う・直す | 推奨買い目の反映、購入フォーム、購入記録と変更履歴 |
| 結果 | 当たったか、予想はどうだったか | 着順（印・馬名つき）、払戻、自分の購入の的中と損益、印と着順の照合、翌朝レビュー |
| 記録 | 根拠や入力を検証したい（上級） | コース・固定入力、snapshot、JSON、処理履歴 |

開いた時のタブ：結果あり→「結果」、発走前→「予想」（予想が未取込なら「再予想」パネルを開いた状態）。

### 再予想（レース画面の「予想」タブ内）
これまで：取込画面へ移動 → snapshot IDを手入力 → パック取得 → コピー → 回答貼付け → 検証 → 確定。
これから：レース画面の中で 3 ステップ。
1. 「最新の入力パックをコピー」（最新snapshotを自動選択）
2. ChatGPTの回答JSONを貼り付けて「検証」（採用版があれば自動でFinal＝差し替え扱い）
3. 内容を確認して「確定」→ その場で予想タブが新しい版に切り替わる

ローカルCLIワーカーへの再予想依頼（ボタン1つで自動実行）は、CLI呼出し枠と固定パックの再作成が絡むため今回は対象外。次段階で検討する。

## 3. 傾向タグ（馬・騎手）

`performances`（run-record-v1）に保存された**そのレース日より前**の走だけから、コードで決定的に計算する（LLMは使わない）。標本数を必ず表示し、少ない時はタグを出さない。

### 馬（直近最大10走）
| 種類 | タグ | 条件 |
| --- | --- | --- |
| 脚質 | 逃げ／先行／差し／追込 | 通過順のある走が3走以上で、同じ脚質が6割以上。どれも6割未満なら「自在」 |
| 道中 | まくり型 | 1角→最終角で平均2頭以上押し上げ（3走以上） |
| 直線 | 末脚堅実／直線失速 | 最終角→着順の平均が+1.5以上／−1.5以下（3走以上） |
| 着順 | 堅実（複勝圏率） | 3着以内率50%以上（3走以上） |
| 着順 | 勝ち切り型 | 勝率30%以上かつ複勝圏のうち勝ちが6割以上（4走以上） |
| 着順 | 善戦止まり | 3着以内率40%以上で勝率10%以下（4走以上） |
| 着順 | ムラあり | 3着以内と、頭数の後ろ半分以下の着順が両方2回以上（4走以上） |
| 近況 | 上昇気配／下降気味 | 直近3走の着順が連続して良化／悪化 |

### 騎手（そのレース日より前の騎乗、直近最大50騎乗）
| 種類 | タグ | 条件 |
| --- | --- | --- |
| 位置取り | 前に行かせる／控える | 逃げ・先行が55%以上／差し・追込が60%以上（通過順のある騎乗10以上） |
| 道中 | 押し上げる | 平均で1頭以上押し上げ（10以上） |
| 成績 | 勝率高／複勝率高 | 勝率20%以上／3着以内率45%以上（10騎乗以上） |

タグはAPI `/races/:id/runs` が返し、レース画面の「出走馬」タブと「予想」タブの馬名横に表示する。予想AIへの入力（固定パック）にはまだ入れない（パックのハッシュと過去の検証を壊さないため、次段階で版を上げて入れる）。
