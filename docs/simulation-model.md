# 数値モデル segment-mc-v1

未検証の仮説モデル。モデル妥当性は試行回数から判断しない。出典付き手動推定能力と、記録済みコース区間を固定入力にする。

| 入力                     | 使用する箇所                                 | 二重評価の防止                     |
| ------------------------ | -------------------------------------------- | ---------------------------------- |
| speed                    | 基礎速度13〜18m/s                            | 近走スコア・距離適性を別加算しない |
| stamina                  | 区間で累積する疲労と勾配への耐性             | 持久力と距離適性を独立に重ねない   |
| acceleration             | 最終直線とゴール前のみ                       | 基礎速度に再加算しない             |
| early_position           | ペースに応じた序盤の努力量                   | 予想着順を速度へ流用しない         |
| jockey_control           | 出遅れ・位置取り揺らぎ・枠由来のコーナー損失 | 騎手の勝率を直接加点しない         |
| draw × curvature         | コーナー距離損失                             | 枠点数を別途加算しない             |
| going_fit × going_factor | 馬×馬場の速度比                              | 馬場適性の重複加点をしない         |
| confidence               | 個体の揺らぎ幅                               | 信頼度を能力の高さとは解釈しない   |

各区間はlength_m / gradient / curvature / phase。区間合計距離をレース距離と照合。ペースはslow/middle/highの混合シナリオ。全馬が同一試行のペースと馬場揺らぎを共有する。個体ごとに出遅れ、位置取り、疲労、加速、区間速度の揺らぎを生成する。seed付きPRNG、全着順から同じ試行で単勝・複勝圏・馬連・ワイド・馬単・三連複・三連単を集計。順不同の買い目はソート、着順券は順序を保存する。

入力の全能力・信頼度は有限な0〜1。欠測がある場合は実行不可とし、文章分析へ戻す。nullを0へ補完しない。入力のsourceには基準・公開・取得時刻を保存し、全て情報締切以前とする。

初期設計の25/15/15/15/10/10/5/5点ウェイトは、この数値エンジンへ二重加点しない。入力能力の推定方法はmodel_versions.feature_version・parameters_jsonに固定して別評価する。このモデルは区間長と時刻以外も多くが仮説。競馬場・距離・脚質・馬場・騎手ごとの標本を集め、未使用期間で比較するまで本番の予測精度を主張しない。

実行上限は10,000回、2〜18頭。ローカルNodeで18頭×10,000回のベンチマークを実施。本番WorkersのCPU時間は未計測で、無料枠内に収まると断定しない。まず100〜1,000回で本番計測し、制限超過時はローカル実行または回数削減を検討する。エンジン・入力・seedが同じ場合の全出力一致をテストしている。

複勝圏（top3_probability）と実際の複勝券の対象順位を区別する。複勝券の分布・EVには公式の `place_positions`（1〜3）が必要。省略時は上位3頭の分布を表示するが、複勝券のEV算定は拒否する。発売頭数・主催者ルールを勝手に推測しない。
