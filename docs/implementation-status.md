## Issue #32: 合意方針への整合と本人Bet編集

券種・買い目・金額の置換編集、元Bet保全、旧新関連監査、古い画面/同時変更の競合拒否、再送、不正変更時の旧Bet維持を実装。発走時刻ちょうど/取消レースを拒否し、AI推奨/予想/シミュレーションを維持。有効新Betだけを精算・集計する。通常取り込み画面はChatGPT主体、Core/MCは検証表示に分離。詳細は [方針監査](operating-policy-audit.md)。

実Sheetsの認証/列/部分障害/複数端末、ChatGPT→Sheets自動受信、実Galaxyは未確認。本番Sheets・既存ChatGPTタスク・Secrets・デプロイの変更なし。

今回の確認: 型チェック・ESLint・102件のテスト・Webビルド・生成Schemaの差分なし。ローカルWranglerで未認証401、同時変更200/409、同操作再送が同一Bet。インストール済みBraveの自動操作で390pxのBet編集・旧新履歴、1440px一覧、通常/検証表示切替、ブラウザ例外なしを確認。長い予想IDの選択欄を画面幅に収めた。`npm run test:runtime` はPlaywrightのChromium、または `SMOKE_BROWSER_PATH` で指定したブラウザを使い、結果をgit対象外の `test-results/` に保存する。

既存依存関係の `npm audit` は3件（moderate 1 / critical 2、Vitestと関連開発依存）を報告した。依存更新は今回実施せず、公開前の確認事項として残す。ブラウザ用ダウンロードはタイムアウト/DNS失敗のためBraveで検証した。
