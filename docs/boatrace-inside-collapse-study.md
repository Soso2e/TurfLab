# Issue #130　1号艇が3着以内に残れない条件

2026年11月27日のデータを固定して検証した。**2・3号艇の級別による相乗項は今回のモデル候補から外す。** 各艇の級別差を個別に使うモデルは現行B13v2Preの再学習版より着外 log loss が低かったが、場別基準率を上回らず、差の95%区間もゼロを含んだ。次の独立比較には場別基準率、B13v2Pre、級別主効果の3群を残す。[Issue #130](https://github.com/Soso2e/TurfLab/issues/130)

[#125の全レース監査](https://github.com/Soso2e/TurfLab/issues/125)のアーカイブ読込・重複排除と、現行B13の順位分布を再利用した。[#129の研究](https://github.com/Soso2e/TurfLab/pull/131)は各艇の内側に上級艇がいる効果と展示Fの加点を対象とする。今回は1号艇の着順を3区分し、2・3号艇の主効果と同時優位の追加価値を評価した。

## モデルと再検証

結果を `W=1着, R=2〜3着, O=4〜6着` とし、級別モデルは次の2段階で学習した。

```text
q = sigmoid(a + w · Z(X)) = P(W以外)
r = sigmoid(b + v · Z(X)) = P(O | W以外)
P(W,R,O) = (1−q, q(1−r), qr)

G(B2,B1,A2,A1) = (0,1,2,3)
D2 = G2−G1, D3 = G3−G1, C = 1[max(G)−min(G) ≤ 1]
X_main = [G1, mean(G4,G5,G6)−G1, D2, D3, C]
X_signed = [X_main, D2×D3]
X_positive = [X_main, max(D2,0)×max(D3,0)]
X_tight = [X_main, D2×C, D3×C]
X_meeting = [X_main, π−(win1+12π)/(n+12), n]
```

- `Z` は各段階の訓練平均と母標準偏差で標準化し ±5 に制限する。分散ゼロ時の尺度は1。差の積は等級が同じ点をゼロとし、積列自体を標準化する。ロジスティック損失平均に `0.08×||w||²/2` を加え、切片には0・1各0.5件を与える。展示タイムの相対値はレース内の標準化秒を使い、ST・タイムとも `艇1−相手艇` が大きいほど相手優位。展示の3艇分Fと1号艇の展示コースを別列にした。
- 場別基準率は、過去の全場クラス比率（各クラス0.5件加算）を12件分として場別件数と混合。H6の `π` はこの場別1号艇勝率、`n` と `win1` は同日同場の前番号で締切前に結果を取得できたレースだけから計算する。
- 日ごとの学習には、その日JST 0時より前に取得済みの過去日の結果版を使用。B13系統は本番と同じ1〜3着が一意の標本で再学習し、120通りから1号艇の3クラスに周辺化した。B13v2Preは完全な締切前展示がある場合に展示モデル、欠損時にはNoEx。級別・展示の研究候補は通常完走ラベルで学習する。B13系統と候補の採点レースは同じ。訓練の一意な上位3着は57 / 127 / 283 / 427件、候補の通常完走は54 / 119 / 268 / 403件。
- 過去データでの2つの追試を実施した。着外には3艇以上が1号艇より先着する必要があるため、相手5艇のうち級別点3番手と1号艇の差を追加した。着外 log loss は主効果から +0.00232［+0.00046, +0.00412］。級別だけで相手3艇目を代表させる仮説は支持されなかった。
- B13v2Preは着外順位を並べる平均適合率に比べ、特に不勝時着外の確率誤差が大きかった。そこで、過去日の時系列予測のみから `q` と `r` の logit に個別の切片を学習した。0・1各10件に相当する縮約を切片に適用。初回は切片ゼロ。11/25〜27の切片は `q` が −0.51〜−0.63、`r` が +0.48〜+0.72。再校正は3クラス・不勝時条件付きの log loss を改善したが、436件の校正可能群の着外 log loss は **+0.00252［−0.00331, +0.00875］**。各段階の誤差が着外確率 `qr` では一部相殺されていた可能性がある。
- 係数を日別に保存した。候補・正則化・STの採否は当日ラベルで選んでいない。新仮説はこのコーパスを見て追加した後ろ向き検証なので、独立期間の結果として扱わない。差の95%区間は場×日クラスタで2,000回再抽出したペア差（最終学習の係数は300回再学習）。4評価日と探索的な複数比較のため、区間は多重比較未調整。
