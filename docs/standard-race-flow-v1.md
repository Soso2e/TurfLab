# TurfLab 標準予想・振り返りフロー v1.0（対応表）

更新: 2026-11-09。[Issue #64](https://github.com/Soso2e/TurfLab/issues/64) の22ステップを、既存の実装・ドキュメント・Issueに対応づけたレビュー用の表。**この文書はコード・スケジュール・モデル重み・DB・Betを変更しない。** 「状態」は2026-11-09時点のmainのコードとドキュメントを読んで判断したもので、実レースでの通し受入（locked予想→公式結果→精算→レビュー）はまだ1件もない（[#61](https://github.com/Soso2e/TurfLab/issues/61)）。

## 区分の定義

- **必須**：毎レース自動で行う。できなければ理由付きで保留し、捏造で埋めない。
- **深掘り**：重賞、欠測が多い、評価が割れた、または想定外の結果だったときだけ行う。
- **定期**：レースごとではなく、サンプルが溜まってから行う（週次・30R以上など）。

状態の凡例：✅ 実装済み（実レース受入は別）／🟡 一部・条件付き／📝 ChatGPTプロンプトの手順のみ（CLI経路にはない）／❌ 未実装

## 決める必要がある点（本人確認）

1. **オッズの扱いの矛盾**：#61は「期待値型・的中重視型を事前確率と**時点付きオッズ**で比較」とし、#20（#17の子Issue）もオッズ期待値を予定しているが、#64のステップ12は「人気・オッズは買い目の判断根拠に使わない」としている。案：能力評価・印・展開には使わず、**買い目の期待値計算にだけ発走前の時点付きオッズを使う**と明記する。どちらにするか決める必要がある。
2. **近走の数**：CLIは最大3走、#64は近5走。CLIの呼出し上限（1日18回）と調査時間を考えると、必須は3走、深掘りのときだけ5走が現実的。
3. **CLIで外部予想を比較するか**：今はChatGPT経路だけ。CLIに入れる場合は、公開時刻・閲覧時刻・利用条件の記録を必須にする。
4. **数値の位置取り予測**：ステップ16で順位誤差を出すには、`lineup` に任意の数値（例：各コーナーの想定順位）を追加する必要がある。追加しない場合は、前／中／後の類型比較だけにする。
5. **未校正確率の表示文言**：MCの出力を「未校正の仮説値」と画面に出すか、校正できるまで確率を非表示にするか。
