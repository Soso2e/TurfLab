# TurfLab 標準予想・振り返りフロー v1.0（対応表）

更新: 2026-11-09。[Issue #64](https://github.com/Soso2e/TurfLab/issues/64) の22ステップを、既存の実装・ドキュメント・Issueに対応づけたレビュー用の表。**この文書はコード・スケジュール・モデル重み・DB・Betを変更しない。** 「状態」は2026-11-09時点のmainのコードとドキュメントを読んで判断したもので、実レースでの通し受入（locked予想→公式結果→精算→レビュー）はまだ1件もない（[#61](https://github.com/Soso2e/TurfLab/issues/61)）。

## 区分の定義

- **必須**：毎レース自動で行う。できなければ理由付きで保留し、捏造で埋めない。
- **深掘り**：重賞、欠測が多い、評価が割れた、または想定外の結果だったときだけ行う。
- **定期**：レースごとではなく、サンプルが溜まってから行う（週次・30R以上など）。

状態の凡例：✅ 実装済み（実レース受入は別）／🟡 一部・条件付き／📝 ChatGPTプロンプトの手順のみ（CLI経路にはない）／❌ 未実装

## 決定事項（2026-11-09 本人確認）

1. **オッズ**：能力評価・印・展開には使わない。**買い目の期待値計算にだけ発走前の時点付きオッズを使う**（取得時刻を記録し、発走後のオッズは使わない）。#61・#20の期待値比較はこの範囲で進め、#64ステップ12の「買い目判断に使わない」はこの決定で置き換える。
2. **近走**：各馬3走。**すでに保存済みの走は再検索しない**（不足分だけ調べる）。
3. **外部予想**：CLIでも比較する。公開時刻・閲覧時刻・出典を記録し、印だけで点を上げない（[external-forecast-audit](external-forecast-audit.md) の規則をそのまま使う）。
4. **隊列予想**：精度はある程度でよい。トークン節約のため数値のフォーマット（各コーナーの想定順位）を基本にし、文章も可。数値が無い馬は類型比較だけにする。
5. **未校正の確率**：画面に出す。「未校正」と明示し、校正済みの値と区別する。

## 最小の次アクション（自動化の効果が大きい順）

1. **1Rの通し受入**（ステップ13→14→15→18）：locked予想・公式結果・精算・レビューを実レースで1件そろえる。これがないと、どの改善も評価できない。
2. **当日馬場傾向の自動集計**（ステップ4）：同日の発走済みRの公式結果（取込済み）から、通過順と着順で逃げ・先行・差しの成績を集計し、サンプル数付きで次のRの調査に渡す。新しい外部取得は不要。
3. **PR #63を翌日レビューへ接続**（ステップ16）：まず類型比較だけで、レビューに展開差を保存する。
4. **ステップ19・21**は30R程度たまってから着手する。
