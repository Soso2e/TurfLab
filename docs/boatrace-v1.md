# 競艇モードと3連単2点 v1

[Issue #102](https://github.com/Soso2e/TurfLab/issues/102) の確定戦略を、競艇専用の予想・仮想購入・精算として運用する。

## 画面と運用

1. TurfLabにログインし、右上の「競艇」を選ぶ。競馬は従来どおり `/` から操作できる。
2. 競艇画面で「公式収集を開始」を押す。公開番組の収集、締切前の凍結、公式結果確認をサーバーのアラームが行う。ブラウザを閉じてもサーバー稼働中は継続する。「収集を停止」で一時停止できる。
3. 「レース」の場フィルターとレース詳細で、締切、2点、候補オッズ、級別、スタート展示、本番進入、公式払戻を確認する。「統計」は展示F補正あり・なしを比較し、「履歴」は開催日ごとの取得件数と精算件数を表示する。

`/boatrace` がホーム、`/boatrace/races` が当日一覧、`/boatrace/races/YYYY-MM-DD` が日別、`/boatrace/races/YYYY-MM-DD-JJ-R` が詳細、`/boatrace/stats` が統計、`/boatrace/history` が履歴。競技切替は選択先のホームに移動し、履歴の戻る・進むから競艇の直接URLを復元できる。切替時は競技ごとに画面を組み直し、競艇の未完了リクエストを中断する。

## 公式データ

| 公式ページ | 取得する項目 |
| --- | --- |
| [本日のレース](https://www.boatrace.jp/owpc/pc/race/index)・[開催場のレース一覧](https://www.boatrace.jp/owpc/pc/race/raceindex?hd=20261122&jcd=12) | 開催日、場コード、レース番号、締切予定時刻、艇番・選手名・公式級別 |
| [2連単](https://www.boatrace.jp/owpc/pc/race/odds2tf?hd=20261122&jcd=12&rno=11)・[3連単](https://www.boatrace.jp/owpc/pc/race/odds3t?hd=20261122&jcd=12&rno=11) | 公式更新時刻、締切予定時刻、締切時表示、1号艇1着の候補オッズ |
| [直前情報](https://www.boatrace.jp/owpc/pc/race/beforeinfo?hd=20261122&jcd=12&rno=11) | 展示ST・F、展示の進入順、展示タイム |
| [結果](https://www.boatrace.jp/owpc/pc/race/raceresult?hd=20261122&jcd=12&rno=11) | 本番の進入・着順、3連単の100円あたり払戻、返還艇、券種の不成立・中止 |

公式ページは公開情報の閲覧用。2025年3月の終了告知はダウンロード案内にある旧「番組表閲覧」「オッズ情報・結果」「競走成績閲覧」が対象で、現行の公開レースページを使用する。公式の [robots.txt](https://www.boatrace.jp/robots.txt) と [サイトポリシー](https://www.boatrace.jp/owpc/pc/extra/policy.html) を2026-11-23に確認した。収集開始は本人操作で行い、1インスタンスで取得開始を750ms以上離す。拒否・過負荷時は待機する。公式ページのHTMLは配布せず、必要なデータと出典URL・取得時刻を本人用ストレージに保存する。[公式ダウンロード案内](https://boatrace.jp/owpc/pc/extra/data/download.html)

## 凍結と精算

- 収集は公式番組の全レースを対象とする。締切予定の145秒前から取得を試行し、番組と両オッズページの中で最も早い締切の3分前から締切直前までに凍結する。両種類の更新表示時刻と取得時刻がこの窓内にあり、更新→取得→凍結の順で、締切時表示が出ていないことが必要。公開直後のデータ遅延や欠損は締切まで再試行する。[公式オッズ表示について](https://www.boatrace.jp/owpc/pc/extra/about.html)
- 1着は1号艇。2着候補は `1-2`〜`1-6` の2連単オッズが低い2艇。公式級別は A1、A2、B1、B2 の順。展示Fがある艇だけ B2→B1、B1→A2 と補正し、A1とA2は保持する。展示Fが未取得の艇は `null` として保存し、級別補正を適用しない。2着の比較が同級なら2連単オッズの小さい艇、それも同値なら艇番の小さい方を選ぶ。3連単は残る4艇のオッズが低い2点、同値は3着艇番の昇順。各100円。
- 100円×2点を展示F補正あり・なしのそれぞれで記録する。全6艇の公式級別、2連単5組、各戦略の3連単4組、凍結日時、公式の更新日時、取得元と取得時刻を保存する。共通の入力から一度の書き込みで凍結し、事後の買い直しは行わない。期限までに級別・必要オッズを確認できないレースは購入記録がなく、理由を表示する。
- 払戻は公式3連単の組番ごとに照合。同着の全対象組番を検証し、公式の返還艇が含まれる券は100円返還する。中止・3連単不成立は全額返還する。特払は公式の金額表示から計上する。購入オッズまたは確定払戻に欠損がある購入レースは未精算。締切後の結果は最大3日間再取得し、確定した記録も締切1時間後と翌日に照合する。訂正を履歴に残し、最新結果で精算する。[公式不成立の例](https://www.boatrace.jp/owpc/pc/race/raceresult?hd=20261107&jcd=02&rno=7)・[公式的中率の扱い](https://www.boatrace.jp/owsp/sp/extra/tb/kinou/kekka.html)
- 統計は直近の約90日間で、両戦略とも精算できた同じレースを集計する。回収率は（払戻＋返還）÷購入額、的中率は全額返還を除く購入レースのうち通常払戻を得た割合。損益は日別・場別、回収率は期間内で締切順の先頭100・500・1000件を表示する。1号艇1着80%は仮説として表示し、公式結果の観測値も件数付きで表示する。

## 保存と検証

- 競艇データは競馬と別の Durable Object の SQLite に保存する。本人認証付き `GET /api/boatrace/archive?date=YYYY-MM-DD` で日別の凍結・公式結果と訂正履歴をJSONで取得できる。既存の競馬 `/api/backup` には含まれないため、サーバー移行時は停止後に DataHome の `state` を保全する。TurfLab-dataへの自動転送には公式データの保存・再配布条件の確認が必要。
- `npm run boatrace:verify -- 2026-11-22 12 11` は、公式ページを直接取得して解析結果と出典を出力する。締切時オッズは `closed` と表示し、検証コマンドから購入記録を作成する経路はない。
- `npm run check` は戦略、先読み防止、欠測、同着、返還、精算、訂正・再読込を検証する。 `npm run test:wizard` は隔離Workerと390px Edge/Chromiumで、競技切替、URL、戻る・進む、再読み込み、連打、遅延レスポンス、アニメーション軽減と既存の競馬操作を検証する。PowerShellで `$env:TURFLAB_BOATRACE_LIVE_TEST='1'` を設定すると、同じ隔離Workerで当日の公式開催場・レース詳細・再起動後の読み返しも照合する。
