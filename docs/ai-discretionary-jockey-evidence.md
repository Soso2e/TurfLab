# AI自由比較レーンと騎手根拠の固定（v3）

## 予想・購入候補を分離
1. 馬・騎手・人馬相性を独立に評価し、3展開と主展開を記録する。数字は根拠であり、最終印はAIの説明付き判断とする。人気・オッズを予想時に用いない。
2. 従来の`hit_picks`（600円）とは別に、`ai_bet_picks`を最大3点・合計1000円・100円刻みでAIが提案する。券種は単勝・複勝・ワイド・馬連・馬単・三連複・三連単に対応。0点の見送りを許可。
3. Python/TypeScriptで券種・馬番・重複・金額と日次5,000円上限を検査し、違反は全件見送り。勝率・期待値を捏造しない。
4. 発走前に不変の`plans/YYYY-MM-DD/*-ai.json`に固定。的中狙い・期待値・厳選・AI自由予想で保存した購入額は自動ベットの仮想資金から差し引き、公式結果の払戻・返還はそこへ戻す。成績はレーン別にも集計する。市場基準の比較記録は評価用。実際の馬券購入や口座への発注は行わない。
5. 既存`jockey_stats`の同場・距離帯・馬場・位置取り・コンビ実績を、対象レースの`lab`予想JSONに`jockey_evidence`として固定しWebに表示。過去時点の標本数、出典、欠測を維持する。

## 現在の範囲
新規DBテーブル・騎手間の継続ランキングモデル・学習済みモデルの自動更新は実装しない。証跡は**各レースの不変Lab JSON内に蓄積**し、将来の集計・研究の正本とする。騎手プロフィールを横断表示するDB/APIは後続PR。
`ai_bet_picks`の配分はオッズ確認前の定性評価であり回収率改善の証明ではない。新旧の採用比較は実レースの公式結果で時系列評価する。
