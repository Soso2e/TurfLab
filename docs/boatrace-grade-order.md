# 競艇：級別順守率 (Grade Order Consistency)

研究専用の事後評価指標 `grade-order-consistency-v1`。公式出走表の元級別 A1 > A2 > B1 > B2 を使い、枠・進入・オッズ・展示F補正は使わない。予想モデルや購入判断は変更しない。

## 指標

異なる級別の艇のペアを比較する。上位級が先着すれば順守、下位級が先着すれば逆転。同級は分母から除外する。順守率 = 順守ペア数 / (順守ペア数 + 逆転ペア数)。異級ペアが0なら null（100%ではない）。

- top3: 1〜3着同士の3組と、各1〜3着艇と残り3艇の9組（最大12組）。4〜6着の相互順序を仮定しない。
- full6: 1〜6着の数値順位が重複なく確認できた場合のみ全15組。失格等の非数値順位や不足時は null。
- exactTop3: 級別の上位3枠と着順の級別列が一致するか。同級艇の入れ替えは許容。
- unorderedTop3: 順不同の上位3級別集合が一致するか。

6艇の元級別が欠損・不正、公式結果が未取得、不成立、返還艇あり、重複順位/艇番、上位3着欠損は判定対象外。対象外理由と母数を記録する。非数値順位を持つ下位艇も、返還なしで上位3着が確定していれば top3 の上位対残り比較には含める。

## 再現

TurfLab-data をチェックアウトして既存研究CLIに渡す。

```sh
npm run boatrace:research -- report ../TurfLab-data
npm run boatrace:research -- run ../TurfLab-data --from 2026-11-21 --to 2026-11-24
```

report は読み取り専用。run / backtest は従来のB11レポートに加え `boatrace-research/evaluations/grade-order-<期間>-<hash>.json` を content-addressed で保存し、manifest に含める。原本は更新しない。

集計は全対象、1号艇勝利/敗北、日付、場、級別構成（降順で枠を無視）、枠順の級別並びごと。異級ペア数による加重集計と対象件数、判定可能件数、同級ペア数を出す。各レースの評価も保存する。上位3着版と全6着版の母数は異なるため混同しない。

既存のDrive集計の70.8%は返還艇等の扱いが異なる暫定標本であり、この実装の公式アーカイブ集計とは一致を保証しない。1号艇敗北は事後の層別であり、事前特徴量ではない。級別と枠番の交絡、データの欠損、同級の多さ、標本数には注意する。予想精度・収益性や因果効果を示す指標ではない。

```sh
npm test -- tests/boatrace-grade-order.test.ts tests/boatrace-research.test.ts
```
