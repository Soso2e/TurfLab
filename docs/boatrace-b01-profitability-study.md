## 1. 結論（エグゼクティブサマリー）

1. **B01の無条件運用では回収率100%超は再現されない。**
   全39日間・精算 **5,892レース**（2026-10-20〜2026-11-27）におけるB01の成績は、的中 **741R（12.58%）**、投入 1,178,400円、純損益 **-226,180円**、回収率 **80.81%**（レース単位ブートストラップ95%CI: **74.01%〜88.15%**、日×場クラスタ95%CI: **74.30%〜87.67%**）、最大ドローダウン **241,480円**、最大連敗 **54** であった。95%信頼区間の上限すら100%を大きく下回る。
2. **過去の小サンプル（321Rで102.4%など）での上振れは、高配当の偏りによる偶然である。**
   - **100R単位（58ブロック）** では **13/58（22.4%）** がROI 100%超（最大 175.10%）となるが、**500R単位（11ブロック）では 0/11（0.0%、最大 90.47%）**、**1,000R単位（5ブロック）では 0/5（0.0%、最大 86.17%）**、**3,000R単位（1ブロック）では 0/1（78.25%）** と、500R以上では一度も100%を超えない。
   - 全体から上位10件の高額払戻（5,210〜11,680円）を除外したトリムドROIは **75.14%** となり、ボートレースの理論払戻率（75%）とほぼ一致する。
3. **「的中率を上げる特徴量」は実在するが、市場オッズに織り込まれるため回収率100%超へは繋がらない。**
   - 探索期間（3,612R）で学習したロジスティック回帰の上位25%（`B01H-logit-top25`）は、独立検証期間（2,280R）でも的中率を **12.37% → 17.66%（+5.29pt）** へ再現性高く引き上げたが、回収率は **76.54%** とベースライン（82.36%）を下回った。
   - 的中レースのうち低配当的中（<1,000円）は1号艇級別・全国勝率が極めて高い一方、高配当的中（>=2,000円）は逆に1号艇が弱めであり、**パリミュチュエル市場では「分かりやすく当たりやすいイン決着」ほどオッズが削られる**構造が定量的に確認された。
4. **時系列分割（探索 3,612R vs 独立検証 2,280R）による2ラウンド計17改善仮説でも、再現性のあるプラス期待値条件は確認できなかった。**
   - 第1ラウンドの場選択（`B01H-disc-top-venues`）は探索 **125.11%** → 独立検証 **97.01%**（上位3的中除外 **66.27%**）へ大きく平均回帰し、場選択バイアスが否定された。
   - 第2ラウンドで検証した「展示Fなし＋級別σ中庸（`B01H-nof-sigma-normal`）」「夕方/ナイター＋展示Fなし（`B01H-late-nof`）」「3号艇Fなし＋外枠Fなし（`B01H-no-f3-no-outerf`）」「11R・12R限定（`B01H-r11-12`）」は、両期間でベースライン比 +7〜18pt の**相対的な損失圧縮（ROI 89〜97%帯）**を示したものの、独立検証で100%を超えた2条件はいずれも**上位3件の高配当を除外すると 78〜81% へ低下**し、ベースラインとの有意差もなかった（`p = 0.28〜0.31`）。
5. **同一レース・同一予算でのモデル比較（B01 / B02 / B13 / B13v2Pre）**:
   全期間再構成（5,748R）では `B13v2Pre` が的中率 **15.14%**・Top-3 Log Loss **4.0574** と予測確率精度で大きく優れるが、オッズを使わず上位2点固定買いする限り、全モデルの回収率は **77.4%〜83.6%**（95%CIは全モデル重複）に収束する。

### 今後の研究への示唆
1. **固定組番（`1-2-3 / 1-3-2`）＋レース条件フィルタでは、控除率25%を恒常的に上回る収益性条件は確認できなかった。** 特に展示F除外・級別σ中庸は「最悪の期待値レース（展示F波乱・極端な級別σ）を避けてROIを80%→89〜93%へ引き上げる」効果までは再現性があるが、100%超の安定再現には至らない。
2. **次の研究フェーズの方向性**: 的中率を上げるだけではオッズ低下に相殺されるため、今後は **「モデル予測確率 $p$（`B13v2Pre` 等）と締切前オッズ $O$ の積（期待回収率 $p \times O$）が閾値を超える買い目だけを選ぶ」期待値フィルタ研究** へ進むべきである（既存の固定済み前向き検証プロトコルとは独立に設計する）。
