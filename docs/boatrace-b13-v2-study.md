## 1. モデル定義（`b13-context-pl-shadow-v2`）

実装: [boatrace-b13-v2.ts](../packages/shared/src/boatrace-b13-v2.ts) / 収集・凍結基盤: [boatrace-collector.ts](../workers/api/src/boatrace-collector.ts) / テスト: [boatrace-b13-v2.test.ts](../tests/boatrace-b13-v2.test.ts) / 研究スクリプト: [boatrace-b13-v2-study.ts](../scripts/boatrace-b13-v2-study.ts)

### 1-1. Contextual Plackett–Luce と共通特徴量相殺の防止
Plackett–Luce の Softmax では全艇に同一の定数を加算すると確率が完全に相殺される。これを防ぐため、レース共通特徴量にはすべて **合計 0 のゼロ和コントラスト** を適用する：
- `innerSlope = [+1.0, +0.4, +0.1, -0.4, -0.5, -0.6]`（総和 `0.0`）
- `b1FocusContrast = [+5/6, -1/6, -1/6, -1/6, -1/6, -1/6]`（総和 `0.0`）

各艇 $i \in \{1..6\}$ の潜在スコア $s_i(x)$：
- **枠別切片** $\theta_1,\dots,\theta_6$（L2 `0.02`）
- **コース別等級係数** $\beta_{\text{grade}, 1..6}$（`A1=4, A2=3, B1=2, B2=1` のレース内平均差、L2 `0.10`）
- **コース別展示F係数** $\beta_{\text{f}, 1..6}$（枠別展示F `0/1`。**一律+1ランク補正を廃止** しコース別に実データ推定）
- **展示タイム偏差** $\beta_{\text{tz}} z_{\text{time}, i}$（レース内6艇の展示タイム z-score）
- **レース水準特徴量**：`time_std`（展示タイムσ）、`st_std`（展示STσ）、`inner_desc`（内3艇等級降順 `1>=2>=3`）、`b1_minus_others`（1号艇−他5艇等級平均）、`ex_wakunari`（展示枠なり `123456`）

### 1-2. 展示欠損専用モデル（`B13v2NoEx`）と `B13v2Pre` ハイブリッド構成
- `B13v2NoEx`：展示情報を一切使わず、枠番切片・コース別等級・`inner_desc`・`b1_minus_others` のみ（14パラメータ）で学習・予測する専用モデル。
- **`B13v2Pre`（メイン）**：締切前展示（`fetchedAt < cutoff`）が完備しているレースは `modelPre`（24パラメータ）で予測し、**欠損時は自動的に `B13v2NoEx` にフォールバック** する。

### 1-3. 締切前展示取得基盤（目標 95% 以上）と予測凍結（データリーク防止）
- 従来は v1 購入枠（30分に1レース）のみ締切前 `beforeinfo` を取得していたため締切前展示取得率が **20.4% (130/636R)** に留まっていた。
- `BoatCollector` に `shadowExhibition` モードを追加し、v1購入枠・残高制限とは独立して **全レースの締切6分前から `beforeinfo` を自動取得（未公開時は90秒/30秒間隔で締切直前までリトライ）** する。
- 取得時点（`now < cutoff`）で `boat_shadow_predictions` テーブルに全モデルの入力スナップショット・出力買い目・確率分布・モデルバージョン・`frozenAt` を write-once 凍結する（展示未取得→締切前展示取得の1回のみアップグレード可、締切後の書き換えは不可）。
- 比較 API：`GET /api/boatrace/shadow` および `GET /api/boatrace/archive?date=YYYY-MM-DD` の `shadowPredictions` に出力。

## 3. 等級・展示Fのコース別影響（実データ推定）

## 6. 前向き検証プロトコルと再現手順

1. **探索期間（2026-11-23〜11-26）の凍結**：本PR時点のモデル構造・特徴量・L2正則化（`l2Intercept=0.02, l2Feature=0.10`）を変更せず、2026-11-27以降の未使用データで評価する。
2. **再現コマンド（オフライン・読取専用）**：
   - 全体レポート：`npm run boatrace:research -- report <TurfLab-data>`
   - 詳細スタディ：`node scripts/run-tool.mjs tsx scripts/boatrace-b13-v2-study.ts <TurfLab-data>`
   - 永続化保存：`npm run boatrace:research -- run <TurfLab-data> --data-sha <sha> --code-sha <sha>`（`evaluations/b13v2-*.json` を追記保存）
3. **昇格条件**：2026-11-27以降の独立期間（最低500R以上目安）で `B13v2Pre`（締切前展示のみ）が既存 `B13` に対し log loss・校正で優位を保ち、払戻・返還込みの仮想回収率の安定性を確認するまで自動仮想購入へ接続しない。
