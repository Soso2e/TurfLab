# 当日トラックバイアス補正（v1、実験）

## 動線と目的

`/local-predictions/trends` は、予想対象レースの発走より前に確定・公表され、
そのAPI呼び出し時点で確認できた**同日・同競馬場・同じ芝/ダート**の公式結果だけから
`track_bias` を生成する。従来の `trends.same_day` の枠傾向を維持しつつ追加する。

- 4角位置から前方・中団・後方を分け、各群の **全該当馬のうち3着内に入った割合** を比較する。
  上位3頭の内訳だけで「後方有利」と判断しない。
- 差し・追込（4角からゴールまでの順位上昇）と、まくり
  （最初の記録コーナーから最終コーナーまでの一定以上の順位上昇）は区別する。
  コーナー情報が取得されていない馬は標本に数えない。
- 距離差400m以内の同日同芝ダートが3レース以上あればそこを優先。
  そうでなければ同芝ダートのみへ範囲を広げ、補正強度を半減する。
- 3レース/18頭以上、前方・後方それぞれ4頭以上などの条件を満たさなければ
  `eligible=false` として **全馬0点補正**。
- eligible時も、平滑化した後方・前方の3着内率差から保守的な仮説点を導き、
  **6項目の `pace` 成分だけ、最大±4点**。馬の能力 `ability`、コース評価、
  馬場 `going`、斤量・枠、騎手評価、オッズ・確率は変更しない。
- AIが予想した位置取り `expected_position` が明瞭な馬にだけ適用。
  「前方〜後方」等の曖昧な位置取りや欠測の点数は変更しない。

## 時点管理・保存

計算時の `computed_at`、対象レース・使用済み確定レースID、距離の採用範囲、
標本数、各群の3着内率、補正点数、適用対象ごとの旧/新 `pace` 点を
予想時点の `lab/YYYY-MM-DD/*.json` に `track_bias_audit` として**不変保存**する。
当日の公式結果の読込は `published_at <= API read time < target race start` で制限し、
通過順位はフィールド単位の取得時刻も検証する。結果を後から再計算して当時の予想へ上書きしない。

既存の `Core` 予想のほかにLabの `pace` 補正済みレコードで追跡可能。
旧モデルと新モデルの予想比較は過去への後付け評価ではなく、
**発走前に固定した予想と公式結果を使う時系列評価**で行う。

## 制約と判定

この値は「当日観測された順位傾向」であり、**馬場固有の因果効果を識別しない**。
ハイペースによる先行崩れ、出走馬の能力差、枠、騎手、距離構成など交絡が残る。
補正幅は経験的な上限で、**的中率や回収率の向上は未検証**。実馬券には発注しない。

`tests/track-bias.test.ts` で時点リーク、芝・ダート混在、標本不足、
まくり判定、元の能力値維持を検証する。
新旧のレーン別的中率・校正・仮想収支・標本数は実データ蓄積後に監査し、
有意な改善が無い場合は補正幅を0に戻す。
