# AXIS-X v0.1 — 勢力図・軸馬・展開適性に基づく実験予想

## 位置づけ
既存の M0r / M1 / 展開モデル P / AI 予想とは独立した**実験用の候補選択モデル**。既存 Core・購入・保存パイプラインへ接続しない。オッズを強弱判定の根拠に使用しない。的中率・収益改善は未検証。

## 検証する仮説（事実ではない）
- 2強: 能力上位2頭のうち少なくとも1頭が3着以内に入る確率は、同条件のベースラインより高いか
- 3強: 上位3頭全馬が3着以内に入る確率は、同条件のベースラインより高いか
- 展開に適合した相手馬を加えると、無補正のスコア上位選択より改善するか

2強・3強は**レース前に固定したスコア**で分類し、レース後に都合よく再分類しない。現行の暫定定義は首位との能力差5点以内の頭数が2または3。1頭なら1強、4頭以上は混戦。頭数不足は分類不可。閾値5点は経験的に妥当と確認された値ではない。

## 計算（暫定）
- 入力: 各馬の基本能力0..100、安定度0..100、展開 slow/normal/fast の適性0..100、騎手相性、隠れ好走材料、敗因改善、リスク
- X-Factor = clamp((展開適性-50)/10 + 騎手相性[-3,3] + 好走材料[0,3] + 敗因改善[0,2] + リスク[-2,0], -15, 15)
- 最終順位スコア = 基本能力 + 0.12×(安定度-50) + 0.15×(展開適性-50) + X-Factor
- 軸馬 = 最終順位1位。相手馬 = 残りから最終順位順に最大3頭。現段階の出力は候補のみで、購入を指示しない。
- **重要**: X-Factor と別の展開項には相関がある。係数は学習済みではなく、二重計上の可能性を含めてアブレーションで検証する。
- 説明できない材料は0、未収集の項目を自動で満点扱いしない。将来は欠損フラグも保持する。

## 検証計画
1. 実NAR過去データを as-of で再構築し、スコア閾値・係数・相手馬数を訓練期間でのみ決定
2. 日付単位のウォークフォワードと競馬場/頭数/距離/馬場/強弱別の層別検証
3. 2強「少なくとも1頭3着以内」、3強「3頭全馬3着以内」を実測し、同様の上位2・3頭選択ベースラインと比較。無作為近似との比較も行う
4. 軸3着内率、相手との同時入着率、買い目点数、的中率、回収率（評価にのみ固定時点オッズと確定払戻を使用）、信頼区間を記録
5. X-Factorなし、展開補正なし、騎手相性なしの除去実験。後付け分析やリークを禁止
6. 現行本番の買い目・金額は変更せず、シャドー評価で先に比較。実測優位が確認できてから採用審査
