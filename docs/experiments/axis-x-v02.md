# AXIS-X v0.2 — 直近4走の条件再現性と馬×騎手相性

独立実験モデル。v0.1 の関数を変更せず、`axis_x_v02.py` に追加。**実NARデータの改善効果は未測定**。本番Worker・定時予想・購入には未接続。

## 入力と暫定計算
- 前走、2走前、3走前、4走前を新しい順に `0.6, 0.2, 0.1, 0.1` で加重。取得できた走だけ重みを再正規化し、coverage (0.6/0.8/0.9/1.0) を併記。全走欠測なら元v0.1能力値を保持し、欠測フラグを付ける。
- 各過去走の「発走前情報だけから得た0..100の実績評価」を入力する。着順単独のスコア変換は本モデルでは**未実装**。順位・ラップ・ペース・対戦相手等のデータ取得契約を別途定義すること。
- 条件一致: 距離は `max(0, 1 - abs(前走距離-今回距離)/800)`、芝⇔ダート変更時の係数0.35、競馬場/馬場状態/ペース差各0.7。比較できない項目は unknown に残す。係数は仮説値、統計的根拠はまだない。
- 条件一致で実績評価を50へ縮小: `補正実績 = 50 + (実績-50)×一致係数`。好走・凡走ともに条件不一致なら転用を弱める。
- 馬の「性格」は観測可能な走行特性に限定。スタートの難しさ、折り合いの難しさ、仕掛け判断の要求を0..100で入力し、騎手のスタート/折り合い/仕掛け能力と対応させる。証拠が揃った場合だけ騎手相性[-3,+3]を算出。内面・性格の断定はしない。
- v0.2の実績評価はv0.1の基本能力を**置換**し、追加加点による二重計上を防ぐ。騎手相性も証拠がある場合だけ既存項目を置換する。ただし旧モデルのX-Factor・展開補正には依然として相関があり、検証が必要。
- 過去走の数値や騎手スキルは**推測で埋めない**。根拠未整備なら本番で生成しない。出典、取得時刻、馬番ID、取消、as-of cutoff、欠測状況を将来の入力契約に記録する。
