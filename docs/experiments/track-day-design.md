## 2026-11-22 開発リプレイの事前登録

- NAR 2026-06〜11 の入手済み原本を使用する。4角欠測が20%を超える競馬場は当該監査期間を通して評価から除外する。分母は取消・除外を除く出走馬。蓄積は続ける。芝ダート不明のレースは監査へ残す。
- 比較は開催場・芝ダート・取得できる回り識別子の一致、距離差400m以下。回りが片側だけ不明な組み合わせは除外する。対象レースに先行する比較可能レースが1R以上必要で、観測群が不足すれば該当特徴を欠測扱いにする。全距離に広げるフォールバックは設けない。通常傾向は対象日以前で5R以上。回りは内外回りを識別できない場合がある。
- 4角と実相対ゲートは別集計。後者は取消・除外を除いて実出走馬番を昇順に詰める。枠番は監査列として保持する。群の境界は整数比較で1/3・2/3をそれぞれ前・後へ入れる。5頭未満、着順不明、1〜3着が1頭ずつ成立しないレースは位置・馬番超過率を集計しない。中止と失格は出走かつ3着外。コーナー群の括弧内は同順位として数える。上がり順位は全出走馬の値がある場合だけ算出する。
- 群別の観測率から同レースの3/出走頭数を引き、各群を n/(n+λ) 倍してから前後差を取る。開発日の初期30%で λ ∈ {0, 5, 10, 20, 40} から次Rの観測前後差に対する二乗誤差最小値を選ぶ。同点なら大きい値。以後は固定する。校正前の出力では縮小値を null にする。
- 能力調整残差は先行日までで学習された M1 の3着内確率を使う。比較対象のレースのうち1Rでも有効な予測がなければ残差を null にする。残差も観測上の関連として扱う。
- まくり集計は最初の計測コーナーで前方群外、4角で前方群、連続する観測コーナー間で3順位以上上昇した馬。3点以上の計測が必要。直線4順位以上の上昇は別指標。走破時計は同場・条件文字列・距離・芝ダート・回りが一致する過去5R以上の勝ち時計中央値と比較する。
- 開催日順の前80%を開発に、最新20%を予約する。予約分は本 CLI では採点しない。H1 と H4 は各対象レースの直前までの比較可能な観測を1回だけ使う。H2 は連続開催の前日最終時点。H3 は馬場遷移ごとの探索で、30Rか5日を下回れば相関を報告しない。
- M1 の特徴量・条件付きロジットを再利用し、両群に通常の位置・ゲート傾向を含める。H1 は early3 を前方が正になるよう符号調整し、縮小済み位置差との積を使う。H4 は内側が正の相対ゲートとゲート超過率の積。欠測フラグを伴うゼロ符号化。各候補は独立に追加し、同じレース・学習期間で比較する。150R以上の先行日データ、7日ごとに再学習、ridge 10 固定。
- 主指標は既存 Plackett–Luce 変換による馬別3着内 binary log loss のレース内平均。候補−基準の区間はJSTの日付で全会場をまとめて2000回再標本化する。片側p値は帰無中心化した日ブロックの差分分布、H1・H4はBH補正、水準0.05、seed 20261122。
- 採用判定には300R・20日以上、改善、95%区間上限0未満、BH通過、リークなし、独立した厳格時点の前向きデータが必要。今回の月次データは探索専用。予測改善、因果効果、馬券収益は個別に扱う。

開発リプレイ v2 は v1 の観測相関集計を改訂した再試行。同順位に平均順位を割り当て、観測相関の95%区間は500回のブロック・ブートストラップで求める。H2は会場・芝ダート別の連続開催ブロック、その他は開催日。v1を確認した開発期間を再使用し、予約日は両試行で未採点。モデル、閾値、学習期間は維持する。
