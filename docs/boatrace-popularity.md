# 競艇：公式確定人気と払戻の記録
公式結果の三連単「人気」列を組番ごとに `BoatResult.popularity` に保存する。旧アーカイブはフィールドなしのまま読める。人気がない場合は未知、払戻からの推定は禁止。同着は勝ち組ごとに別観測とし、母数はレース数と勝ち組数を分離。確定後の市場情報であり、事前予測入力には使用しない。

## オフライン集計
```sh
npx tsx scripts/boatrace-popularity.ts report ../TurfLab-data
```
日別アーカイブを既存CLIで統合し、人気別件数・既知分母割合・平均/中央値/最小/最大と、千円単位の払戻分布を出力する。未取得人気の件数も報告する。

## 過去分の補完
```sh
npx tsx scripts/boatrace-popularity.ts backfill ../TurfLab-data 20
```
1回最大100レース。既存の公式サイト取得制限・間隔を尊重し、取得例外時に打ち切る。保存は `boatrace-research/popularity/observations-*.json` と `report-*.json` への新規追記のみ。公式結果の全勝ち組・払戻額が一致しない場合は補完せず、理由を記録。元アーカイブと結果取得時刻を変更しない。繰り返し実行して未取得分を補完。実行後の研究ファイルはレビューしてTurfLab-dataにコミットする。既知分母が小さい場合の人気分布は母集団全体の推定ではない。

B13との比較はPR #126のマージ後に、事前凍結または時系列再構成した120通りの分布から、結果組番の確率・モデル順位と公式確定人気順位を事後照合する。市場順位の差は観測された勝ち組に限られるため、全120組の市場確率との比較とは呼ばない。予測・購入経路に接続しない。
