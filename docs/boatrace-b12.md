# B12 — Similar Race Model (研究専用)

B11を置換せず、過去の公式級別の並びから着順分布を推定する。実購入・仮想購入台帳の変更なし。既存の非公開 TurfLab-data アーカイブを読取り専用で使用し、公開repoに実データを保存しない。

## 数学仕様 v1

- A1=4, A2=3, B1=2, B2=1、艇番順の6次元ベクトル。元の公式級別のみ。
- 距離 D = Σ|x_i-y_i|。全履歴を対象に距離0〜2を抽出し、重み w=0.5^D。距離別件数・類似レースID・結果・重みを返す。
- 120通りの3連単について過去の全適格レースの頻度を基準分布 P0 とする（全カテゴリに合計1件の一様擬似カウント）。
- P(c)=(Σ w I(result=c)+αP0(c))/(Σw+α)、α=10。3連複20通りは該当6順列を合計する。艇別1着、3着内も周辺化する。
- N_eff=(Σw)^2/Σw²。N_eff>=30 かつ Σw>=10 を暫定十分条件とする。各券種の上位2組の確率合計が同じ組の基準確率合計の1.2倍以上なら研究上の傾向フラグを立てる。これは統計的有意性でも収益性でもない。閾値は未最適化。条件不足は insufficient、入力不明は unjudged。確率参考値を出す場合も採用しない。
- 同点は組番昇順。オッズを確率推定に使用しない。3連単/3連複を別に順位付けし、上位2組を研究評価に使用する。

## 時点と対象

アーカイブを全日付から読み込んで既存の mergeBoatArchives で重複解消する。過去レースは予想時刻以前に結果が取得済みで、締切前の級別スナップショットが存在するものに限定。対象自身・未来結果・不正な時刻・級別欠損・中止・返還・同着・特払は除外する。最新訂正の取得時刻が予想時刻後なら保守的に除外する（当時の旧版の再構築は未対応）。バックテストは締切1ms前を再構成時点とし、実際の前向き凍結とは区別する。

## 実行

```sh
npx tsx scripts/boatrace-b12-cli.ts backtest ../TurfLab-data
npx tsx scripts/boatrace-b12-cli.ts backtest ../TurfLab-data 2026-11-22 2026-11-25
npx tsx scripts/boatrace-b12-cli.ts predict ../TurfLab-data <raceId> <asOf-ISO>
npx vitest run tests/boatrace-b12.test.ts
```

評価期間指定は対象にだけ適用し、学習用履歴は切らない。入力ファイルSHA256、設定、予測・実績、決定的ハッシュを標準出力する。B08固定2点とB11（σ制限/進入ゲートなし）を同一評価対象で比較し、B11見送りは別分母。B12十分条件を満たした対象の的中数・log loss・Brier scoreを算出する。3連単・3連複の回収率は未実装で null とする。3連複払戻を3連単から推定しない。

## 残作業

CI・実アーカイブによる検証、十分条件の通過率確認、期間外検証で重み・閾値を調整、3連複公式払戻/返還の収集と同額比較、前向き凍結とUI表示。平均ST等の特徴量は別バージョンで検証する。
