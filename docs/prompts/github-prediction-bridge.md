# 固定パックから予想を新規保存するためのタスク指示

この指示の利用前に、対象の定時実行環境が非公開GitHubのファイルを読み、新規ファイルを保存できることを試験ブランチで実証する。通常会話での実行成功だけで朝9時タスクへ移行しない。

---

非公開 `Soso2e/TurfLab-data` の当日JSTに対応する `packs/` を確認し、本人確認済みの入力がそろう最大5Rだけを分析してください。packsの作成・出馬表の補完・既存ファイルの変更は行わないでください。

1. 各ファイルの `pack` を読み、raceの日付と発走時刻、情報締切、全頭・取消、出典、モデル、unknownsを確認してください。複数packが同一レースにあり使用版が指定されていない場合は、勝手に選ばず確認待ちにしてください。
2. 固定パックの本人確認済み出典・情報締切以前の許諾済み資料だけを使用してください。出馬表だけで能力や過去成績の根拠が不足するなら、採点を作らず不足内容を報告してください。架空の外部ID・出典・過去走・能力値・確率で補完しないでください。
3. オッズ・人気を馬の評価、展開、予想、買い目の根拠に使用しないでください。
4. 全有効出走馬の6評価項目と根拠、スロー・平均・ハイの3展開それぞれの全馬隊列と有利不利、主展開と根拠、参考買い目と100円単位の参考額、未確認事項を `pack.answer_schema` の正確な項目名で記入してください。参考額は1R最大1,000円。未算出の確率やMC実行証跡を作らないでください。
5. 外側の `prediction_template` をコピーし `answer` を完成させてください。`answer.pack_hash` を含むhash、内部ID、モデルID、情報締切はパックの実際の値をコピーし、計算・推測しないでください。`generated_at` は実際の生成時刻のタイムゾーン付きISO日時です。
6. 通常Morningは外側の `prediction_path` に新規JSONを1R1ファイルで保存してください。既存同名ファイルがある場合は上書きせず、その版を再生成しないでください。本人の修正指示がある場合だけ新しいversion/pathを使用し、旧版を残してください。
7. Finalは本人が指定した新snapshot・直前の保存済み予想ID・変更種別/理由/出典IDがそろう場合だけ別ファイルにしてください。オッズ変動をFinal理由にしないでください。再分析は別版として保存してもCore自動確定の対象外です。
8. 発走後に新しいMorning/Finalを保存しないでください。未登録レース、pack不足、未確認の出典や外部ID、資料不足、GitHubへの保存権限不足は「確認待ち」として理由を報告してください。

完了時は実際に新規保存できたファイルとcommitだけを報告してください。GitHubへ保存したこととTurfLabへ取り込まれたことを分けてください。TurfLab側のCore読み返しを確認できなければ、取込成功と記載しないでください。AI参考額を本人の仮想購入として扱わないでください。
