競馬予想で考慮する **53項目（12カテゴリ）** の一覧。

### 1. 馬場（6項目）
- [ ] 芝・ダート状態
- [ ] 含水率
- [ ] クッション値
- [ ] 内ラチ沿いの傷み
- [ ] 使用コース
- [ ] 天候・降雨状況

### 2. 競馬場・コース（5項目）
- [ ] 競馬場適性
- [ ] 右回り・左回り適性
- [ ] 直線の長さと坂
- [ ] コーナー形状・数
- [ ] 同コース実績

### 3. 当日傾向（4項目）
- [ ] 先行・差しの有利不利
- [ ] 内外枠の有利不利
- [ ] 時計の出やすさ
- [ ] 通過順位・上がり傾向

### 4. 走破タイム・速度（6項目）
- [ ] 過去走破タイム
- [ ] 同距離ベストタイム
- [ ] 平均走破タイム
- [ ] 距離差補正
- [ ] 競馬場・馬場差補正
- [ ] 上がり3F

### 5. 過去実績（5項目）
- [ ] 着順
- [ ] 勝利数・連勝
- [ ] 着差
- [ ] 相手レベル
- [ ] 直接対決

### 6. 展開・ペース（5項目）
- [ ] 脚質（逃げ・先行・差し・追込）
- [ ] 先行馬の頭数
- [ ] スロー・平均・ハイペースの想定
- [ ] 道中の位置取り
- [ ] 展開による有利不利

### 7. 距離適性（3項目）
- [ ] 同距離での実績
- [ ] 距離短縮・延長への対応
- [ ] スピードと持久力のバランス

### 8. 枠順・馬番（3項目）
- [ ] 内枠・外枠
- [ ] スタートから最初のコーナーまでの距離
- [ ] 枠順と脚質の相性

### 9. 騎手・人馬適性（4項目）
- [ ] 騎手の実績
- [ ] 騎手のコース適性
- [ ] 騎手と馬のコンビ実績
- [ ] 騎手の戦術と馬の脚質の相性

### 10. 成長性・コンディション（4項目）
- [ ] 2歳馬の成長余地
- [ ] 出走経験の少なさによる未知能力
- [ ] 前走からの上積み
- [ ] 近走の調子・安定性

### 11. 外部予想・集合知（4項目）
- [ ] 競馬新聞の専門記者予想
- [ ] 競馬情報サイトの分析
- [ ] AI予想モデルの評価
- [ ] SNS・競馬関係者の意見

### 12. シミュレーション・不確実性（4項目）
- [ ] 各馬の相対能力値
- [ ] 展開別の勝率
- [ ] モンテカルロシミュレーション
- [ ] 勝率・3着以内確率

### 分析・評価時の原則
- 分析順序：馬場 → 当日傾向 → 展開 → 能力・タイム → コース・距離 → 枠順 → 騎手 → コンディション → 外部評価 → シミュレーション。
- 独自分析を先に行い、その後で外部予想と比較する。
- オッズ・人気を能力評価・予想・買い目の判断根拠に使用しない。
- 勝率・3着以内確率は、校正が済むまでは未校正のモデル推定値として扱う。
