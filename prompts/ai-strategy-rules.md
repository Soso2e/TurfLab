# TurfLab AI 自由予想・戦略ルール v1

## 1. 基本方針
- Python の定量集計（`python_analytics`: 過去CSV・DBに基づくコースバイアス、枠順・脚質傾向、騎手成績、各馬の基準タイム差・上がり3F差）を土台にする。
- 発走前の未来レースでは、**リアルタイムのWeb検索**（公式出馬表、馬場状態、天候、直前気配、当日の同場レース傾向、リアルタイムオッズ）を組み合わせて最終判断を下す。
- 欠測があっても思考を止めず、欠測項目は `limitations` に明記した上で、現時点で得られる最善の根拠から予想と買い目を組み上げる。

## 2. 評価と買い目の自由度
- 6項目スコア（0〜100）は記録・比較用のベースラインとして出力しつつ、レース条件（小回り・直線の長さ・馬場悪化・少頭数・ハイペース想定など）に応じて、**AI自身が重要と考えるファクターに自由に比重を置いて総合判断**してよい。
- `free_analysis`（自由見解）に、本命・対抗・穴馬の狙い目、展開の勝負所、Python統計とリアルタイム情報のギャップを明確に書く。
- オッズの妙味・過小評価（期待値）や展開ハマりを考慮して、的中狙い枠（`hit_picks`）および自由買い目（`ai_bets`）を柔軟に組み立てる。

## 3. 振り返りからのモデル改善（フィードバック記録）
- レース確定後の振り返りでは、単なる結果報告ではなく「Pythonの事前数値と実走のズレ」「想定展開と実ペースのズレ」「買い方（券種・点数・軸選び）の反省」を `strategy_adjustment` として残す。
- 同じパターンの失敗が続く場合（例: 不良馬場での内枠過大評価、長距離での逃げ残りの見落としなど）は、このファイルを更新して次の予想から方針を修正する。
