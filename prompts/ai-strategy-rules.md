# TurfLab AI 自由予想・戦略ルール v1

## 1. 基本方針
- Python の定量集計（`python_analytics`: 過去CSV・DBに基づくコースバイアス、枠順・脚質傾向、騎手成績、各馬の基準タイム差・上がり3F差）を土台にする。
- 発走前の未来レースでは、**リアルタイムのWeb検索**（公式出馬表、馬場状態、天候、直前気配、当日の同場レース傾向、リアルタイムオッズ）を組み合わせて最終判断を下す。
- 欠測があっても思考を止めず、欠測項目は `limitations` に明記した上で、現時点で得られる最善の根拠から予想と買い目を組み上げる。

## 2. 評価と買い目の自由度
- 6項目スコア（0〜100）は記録・比較用のベースラインとして出力しつつ、レース条件（小回り・直線の長さ・馬場悪化・少頭数・ハイペース想定など）に応じて、**AI自身が重要と考えるファクターに自由に比重を置いて総合判断**してよい。
- `free_analysis`（自由見解）に、本命・対抗・穴馬の狙い目、展開の勝負所、Python統計とリアルタイム情報のギャップを明確に書く。
- オッズの妙味・過小評価（期待値）や展開ハマりを考慮して、的中狙い枠（`hit_picks`）および自由買い目（`ai_bets`）を柔軟に組み立てる。

## 3. 振り返りからのモデル改善（フィードバック記録）
- レース確定後の振り返りでは、単なる結果報告ではなく「Pythonの事前数値と実走のズレ」「想定展開と実ペースのズレ」「買い方（券種・点数・軸選び）の反省」を `strategy_adjustment` として残す。
- 同じパターンの失敗が続く場合（例: 不良馬場での内枠過大評価、長距離での逃げ残りの見落としなど）は、このファイルを更新して次の予想から方針を修正する。

## 4. 精査・統合済みの実戦ルール（2026-11-21 整理）
- **トリガミ回避と買い目分散**: 上位3〜4頭のワイドBOX6点均等買いや単一軸への全点依存を避ける。上位拮抗・低配当想定時はオッズや信頼度に応じて2〜3点へ集約するか馬連／馬単への配分・流し構成を検討し、本命が崩れるシナリオ（先行競合等）に備えて相手本線同士の組合せも確保する。
- **欠測データと実力不足の分離**: 斤量・馬場適性・同コース実績・人馬コンビ実績などが `null`（`covered_weight < 1`）の馬を明確なマイナス実績と混同して機械的に除外しない。他場上級クラス実績馬や初コンビ・同距離未経験馬は能力・他距離指標との重みを補正して評価する。少標本コンビ不振だけで騎手の同コース多騎乗実績を過度に相殺しない（縮小推定的に扱う）。
- **確信度（`confidence`）の欠測連動キャリブレーション**: `identity_confidence="name_only"`、斤量欠測、コンポーネント `null` 率が高い、休養明け馬が複数いる、オッズ未参照といった不確実性が高い条件では `confidence` の上限を抑え、0.95超のような過大な値を出さない。
- **スコア順位と定性判断・買い目の整合**: スコア上位3頭以内を「休養明け」などの単一理由だけで買い目から完全除外しない（配分調整または当日馬体重確認後の条件付き減点に留める）。スコア1位と中心評価が逆転する場合や下位スコア馬を買い目に繰り上げる場合は定量根拠を明記する。
- **枠順・展開・条件替わりの過大割引防止**: 斤量欠測時でも枠番・馬番の幾何学的な距離損益（内枠ロス軽減・大外負荷）は独立評価する。内枠（1〜2枠）＋同コース実績騎手の先行馬を実ペース未確定の段階で一律に大きく割り引かない。下級条件連続好走でコース適性の高い馬や、不良馬場など極端な条件の近走敗戦から得意条件へ戻る馬も過度に割り引かない。
- **直前条件確認と出走取消時の再計算**: 発走前は公式個体照合・確定斤量・馬場状態・馬体重の確認を徹底する。出走取消（`scratched`）を検知した場合は先行隊列を再評価し、取消馬を含む買い目の資金を他点へ再配分する。
