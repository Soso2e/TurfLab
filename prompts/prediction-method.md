# 予想モデルの評価手順 v1

53項目を独立した加点項目として合計すると、過去実績・タイム・相手関係などを重複評価してしまう。項目は根拠の棚卸しに使い、6評価へ次のようにまとめる。

| Core項目 | 主な根拠 | 評価 |
| --- | --- | --- |
| ability | 近走の走破内容、相手、着差、上がり、条件差 | 同じレースの相手と比較した能力 |
| course | 左右回り、坂、コーナー、コース実績、距離 | 当該形状・距離への適性 |
| pace | 脚質、先行馬数、3展開での位置、過去の通過順位 | 主想定の展開で能力を発揮できる度合い |
| going | 当日馬場・天候、過去の馬場別成績、走法の観測 | 観測された当日条件への適性 |
| draw_weight | 枠、初角までの距離、脚質、斤量変化 | 枠と斤量が走りやすさに与える影響 |
| horse_jockey_course | 騎手の戦術、コース実績、コンビの過去の走り | 今回の戦術の実現可能性 |

点数は0〜100の主観的な相対評価で、確率とは独立。80以上は明確な適合根拠、60〜79は適合方向の根拠、40〜59は観測された長短が拮抗、20〜39は不適合方向、20未満は明確な不適合を表す。欠測を50へ置き換えない。点数ごとに根拠と反証、推定の確信度を説明する。未経験の距離・馬場・組合せについては既知条件から推定できる理由を示し、推定不能ならnull。

探索時に全馬の根拠が揃わないレースは参考分析として保存し、残り枠では過去走が多い別レースを優先する。53項目すべての数値化は必要条件にしないが、正式6評価を支える根拠は必要。外部の印・評価点だけで穴埋めしない。

時計比較は距離・競馬場・馬場・負担重量の違いを記載する。検証された補正式がない場合は「補正未実施」とし、疑似的な精密数値を作らない。成長性や少出走の未知能力は点数の確信度とシナリオ幅で表す。

シミュレーションは入力能力・分散・相関の根拠が揃う場合に限る。未実行のMonte Carlo、校正未実施の勝率は算出済みと書かない。結果からの改善は、観測と原因仮説を分け、次のレースで再検証する。過去の保存済み予想を編集しない。
